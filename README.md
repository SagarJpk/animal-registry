# Animal Digital ID Registry Foundation

This keeps the existing Bujji-style profile and adds an unlimited-pet registry foundation.

## Files to upload to GitHub
- index.html
- registry.html
- data.js
- profile.js
- style.css
- bujji.jpg
- pinku.jpg

Keep the existing `bujji.jpg`. Upload Pinku's photo as `pinku.jpg`.

## URLs
Registry: https://sagarjpk.github.io/animal-id/registry.html
Bujji: https://sagarjpk.github.io/animal-id/?id=bujji
Pinku: https://sagarjpk.github.io/animal-id/?id=pinku

The old root URL `/animal-id/` still opens Bujji for backward compatibility.

## Add another pet
1. Upload the photo.
2. Open `data.js`.
3. Copy the Pinku object.
4. Change `id`, `animalId`, name, details, photo, and records.
5. Commit to GitHub.

Do not describe these IDs as government-issued. They are private registry IDs.
